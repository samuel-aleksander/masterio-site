masterio

Privacy policy

Last updated October 27, 2026

masterio is a personal tool that runs on its owner's own Mac. It has no other users and no servers. This policy describes what it does with Google account data.

What it accesses

  • Gmail, read-only (gmail.readonly): to search and read the owner's email. masterio cannot send, delete, label or change any email.
  • Google Drive files it creates (drive.file): Docs and Sheets that masterio itself created. Google blocks it from every other file.
  • Google Sheets (spreadsheets): used only to add rows to the one spreadsheet the owner picks.

Where data is kept

Sign-in tokens are stored in the macOS Keychain on the owner's Mac. Email content, notes and drafts are stored only in a private folder on that Mac. Nothing is stored on any server run for masterio, because there is none.

Who else sees it

To answer the owner's requests, the text of selected emails is sent to the AI model the owner has chosen: OpenAI's Codex (with training on this data turned off) or a model running locally on the Mac. Nothing else is shared. Data is never sold, never used for advertising and never shared with anyone else.

Google API Services User Data Policy

masterio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/connections. Running masterio mail disconnect also deletes the saved token from the Keychain.
